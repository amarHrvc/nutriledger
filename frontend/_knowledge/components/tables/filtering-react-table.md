# FilteringDataTables Component (Demo)

**File:** `src/views/react-table/ColumnVisibility.tsx` or `EditableDataTables.tsx` (see also: KitchenSink, RowSelection)  
**Reusable:** demo (learning/reference examples)  
**Type:** Reference Implementation  

---

## Purpose

Collection of TanStack React Table v8 demo examples showcasing different features:
- ColumnVisibility.tsx - Show/hide columns dynamically
- EditableDataTables.tsx - Inline row editing
- KitchenSink.tsx - Full-featured example (filtering, sorting, pagination)
- RowSelection.tsx - Multi-select with actions

---

## Learning Path

1. Start with **BasicDataTables** - core table structure
2. Move to **RowSelection** - add multi-select
3. Then **ColumnVisibility** - dynamic columns
4. Then **EditableDataTables** - inline editing
5. Finally **KitchenSink** - all features combined

---

## Bundle

- `@tanstack/react-table` ^8.x
- `@mui/material` ^5.x
- All demos use static data
