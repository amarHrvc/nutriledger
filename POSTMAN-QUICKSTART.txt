# 🚀 POSTMAN QUICK START CARD

## 📥 Import (30 seconds)

```
1. Open Postman Desktop
2. Click "Import" (top-left)
3. Upload: postman-nutri-ledger-collection.json
4. Upload: postman-nutri-ledger-env.json
5. Click collection "Run" button
```

---

## 🧪 Test Flow (2 minutes)

| # | Request | Token | Input | Output |
|---|---------|-------|-------|--------|
| 01 | Login (Admin) | — | email/password | `admin_token` ✓ |
| 02 | Login (Doctor) | — | email/password | `doctor_token` ✓ |
| 03 | Get Profile | `admin_token` | — | user data ✓ |
| 04 | Create Patient | `admin_token` | patient data | `patient_id` ✓ |
| 05 | List Patients | `admin_token` | page=1 | paginated list ✓ |
| 06 | Get Patient | `admin_token` | {patient_id} | patient record ✓ |
| 07 | Update Patient | `admin_token` | patient data | updated ✓ |
| 08 | Create Visit | `doctor_token` | visit data | `visit_id` ✓ |
| 09 | List Visits | `doctor_token` | {patient_id} | paginated list ✓ |
| 10 | Get Visit | `doctor_token` | {patient_id}/{visit_id} | visit record ✓ |
| 11 | Update Visit | `doctor_token` | visit data | updated ✓ |
| 12 | Delete Visit | `admin_token` | {patient_id}/{visit_id} | deleted ✓ |
| 13 | Doctor Cannot Delete | `doctor_token` | {patient_id}/999 | 403 ✓ |
| 14 | Patient Cannot Create | `patient_token` | {patient_id} | 403 ✓ |
| 15 | Guest No Access | — | /patients | 401 ✓ |
| 16 | Data Summary | — | — | logs all data ✓ |

## 💡 Key Variables (Auto-Populated)

```
admin_token    ← Captured from request 01
doctor_token   ← Captured from request 02
patient_id     ← Captured from request 04
visit_id       ← Captured from request 08
```

Use `{{admin_token}}` in request headers → automatically replaced with value

## 🛠️ Troubleshooting

| Issue | Fix |
|-------|-----|
| "Unauthenticated" | Re-run request 01 (Login Admin) |
| "Patient not found" | patient_id is empty; create patient first |
| "Access denied" (403) | Expected for requests 13-14 (auth tests) |
| "Connection refused" | Start Laravel: `composer run dev` |
| Variables empty | Ensure "NutriLabs Local" environment is selected |
