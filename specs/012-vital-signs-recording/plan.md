# Implementation Plan: Vital Signs Recording & History

**Branch**: `012-vital-signs-recording` | **Date**: 2026-05-10 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/012-vital-signs-recording/spec.md`

---

## Summary

Add a `vital_signs` table (one record per visit) and a full CRUD API nested under `patients/{patient}/visits/{visit}/vitals`, plus a flat patient-level history endpoint `GET /patients/{patient}/vitals`. A `VitalSignService` handles BMI computation and writes. A `VitalSignPolicy` enforces the three-role access model. On the frontend, the Visit Detail page's "Coming soon" callout is replaced with a vitals card + form dialog; the Patient profile gains a new Vitals history tab. The resource and history endpoint are designed to be AI-readable without secondary queries.

## Implementation Phases

### Phase BE-1 — Migration: create_vital_signs_table

**Goal**: Create the `vital_signs` table with all measurement columns and a unique FK to `visits`.

**Inputs**: `database/migrations/` (existing), `visits` table schema.

**Outputs**: `database/migrations/xxxx_create_vital_signs_table.php`

**Steps**:
1. `php artisan make:migration create_vital_signs_table --no-interaction`
2. Fill `up()`:
```php
Schema::create('vital_signs', function (Blueprint $table) {
    $table->id();
    $table->foreignId('visit_id')->unique()->constrained()->cascadeOnDelete();
    $table->unsignedSmallInteger('systolic_bp')->nullable();
    $table->unsignedSmallInteger('diastolic_bp')->nullable();
    $table->unsignedSmallInteger('heart_rate')->nullable();
    $table->decimal('temperature', 4, 1)->nullable();
    $table->decimal('weight', 5, 2)->nullable();
    $table->decimal('height', 5, 2)->nullable();
    $table->decimal('bmi', 4, 2)->nullable();
    $table->timestamps();
});
```
3. Fill `down()`: `Schema::dropIfExists('vital_signs');`
4. Run `php artisan migrate`

**Decision rationale**: `visit_id` is UNIQUE — one vitals record per visit maximum. `cascadeOnDelete` removes orphaned vitals if a visit is deleted. All measurement columns are nullable (partial records allowed). BMI is stored — not computed at read time — so historical values are preserved when weight or height is later corrected.

**Verification**: `php artisan migrate && php artisan test --filter=VitalSignMigration`

### Phase BE-2 — Model: VitalSign

**Goal**: `VitalSign` model with correct casts, a `computedFlags` accessor, and relationships.

**Inputs**: Migration from BE-1, `Visit` model.

**Outputs**: `app/Models/VitalSign.php`

**Steps**:
```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsTo;

class VitalSign extends Model
{
    protected $fillable = [
        'visit_id', 'systolic_bp', 'diastolic_bp', 'heart_rate',
        'temperature', 'weight', 'height', 'bmi',
    ];

    public function casts(): array
    {
        return [
            'systolic_bp'  => 'integer',
            'diastolic_bp' => 'integer',
            'heart_rate'   => 'integer',
            'temperature'  => 'decimal:1',
            'weight'       => 'decimal:2',
            'height'       => 'decimal:2',
            'bmi'          => 'decimal:2',
        ];
    }

    public function visit(): BelongsTo
    {
        return $this->belongsTo(Visit::class);
    }

    /** Compute abnormal flags at read time — not stored. */
    public function getComputedFlagsAttribute(): array
    {
        $flags = [];

        if ($this->systolic_bp !== null && ($this->systolic_bp > 140 || $this->systolic_bp < 90)) {
            $flags[] = ['field' => 'systolic_bp', 'value' => $this->systolic_bp, 'threshold' => '90–140 mmHg'];
        }
        if ($this->diastolic_bp !== null && ($this->diastolic_bp > 90 || $this->diastolic_bp < 60)) {
            $flags[] = ['field' => 'diastolic_bp', 'value' => $this->diastolic_bp, 'threshold' => '60–90 mmHg'];
        }
        if ($this->heart_rate !== null && ($this->heart_rate > 100 || $this->heart_rate < 50)) {
            $flags[] = ['field' => 'heart_rate', 'value' => $this->heart_rate, 'threshold' => '50–100 bpm'];
        }
        if ($this->temperature !== null && ((float) $this->temperature > 37.5 || (float) $this->temperature < 36.0)) {
            $flags[] = ['field' => 'temperature', 'value' => $this->temperature, 'threshold' => '36.0–37.5 °C'];
        }
        if ($this->bmi !== null) {
            $bmi = (float) $this->bmi;
            $category = match (true) {
                $bmi < 18.5  => 'underweight',
                $bmi >= 30.0 => 'obese',
                $bmi >= 25.0 => 'overweight',
                default      => null,
            };
            if ($category !== null) {
                $flags[] = ['field' => 'bmi', 'value' => $this->bmi, 'category' => $category];
            }
        }

        return $flags;
    }
}
```

### Phase BE-3 — Policy: VitalSignPolicy

**Goal**: Authorize all vitals actions per the three-role model.

**Inputs**: `app/Policies/VisitPolicy.php` (pattern), `VitalSign` model, `Visit` model.

**Outputs**: `app/Policies/VitalSignPolicy.php`

**Steps**:
```php
<?php

namespace App\Policies;

use App\Models\User;
use App\Models\VitalSign;
use App\Models\Visit;

class VitalSignPolicy
{
    /** Doctor/admin can view any vitals; patient only own. */
    public function view(User $user, VitalSign $vitalSign): bool
    {
        if ($user->isAdmin() || $user->isDoctor()) {
            return true;
        }

        // Patient: visit must belong to their patient record
        return $user->isPatient()
            && $vitalSign->visit->patient->user_id === $user->id;
    }

    /** Doctor can record vitals only for visits they conducted; admin unrestricted. */
    public function create(User $user, Visit $visit): bool
    {
        if ($user->isAdmin()) {
            return true;
        }

        return $user->isDoctor() && $visit->doctor_id === $user->id;
    }

    /** Same restriction as create — doctor must have conducted the visit. */
    public function update(User $user, VitalSign $vitalSign): bool
    {
        if ($user->isAdmin()) {
            return true;
        }

        return $user->isDoctor()
            && $vitalSign->visit->doctor_id === $user->id;
    }

    /** Admin only. */
    public function delete(User $user, VitalSign $vitalSign): bool
    {
        return $user->isAdmin();
    }

    /** Doctor/admin can view patient's vitals history; patient only own. */
    public function viewHistory(User $user, \App\Models\Patient $patient): bool
    {
        if ($user->isAdmin() || $user->isDoctor()) {
            return true;
        }

        return $user->isPatient() && $patient->user_id === $user->id;
    }
}
```

**StoreVitalSignRequest**:

<?php

namespace App\Http\Requests;

use App\Models\Visit;
use Illuminate\Foundation\Http\FormRequest;

class StoreVitalSignRequest extends FormRequest
{
    public function authorize(): bool
    {
        $visit = $this->route('visit');
        return $this->user()->can('create', [VitalSign::class, $visit]);
    }

    public function rules(): array
    {
        return [
            'systolic_bp'  => ['nullable', 'integer', 'min:0', 'max:350'],
            'diastolic_bp' => ['nullable', 'integer', 'min:0', 'max:250'],
            'heart_rate'   => ['nullable', 'integer', 'min:0', 'max:300'],
            'temperature'  => ['nullable', 'numeric', 'min:30', 'max:45'],
            'weight'       => ['nullable', 'numeric', 'min:0', 'max:700'],
            'height'       => ['nullable', 'numeric', 'min:0', 'max:300'],
        ];
    }

    public function withValidator($validator): void
    {
        $validator->after(function ($validator): void {
            $fields = ['systolic_bp', 'diastolic_bp', 'heart_rate', 'temperature', 'weight', 'height'];
            $hasOne = collect($fields)->some(fn (string $f) => filled($this->input($f)));
            if (! $hasOne) {
                $validator->errors()->add('vitals', 'At least one measurement must be provided.');
            }
        });
    }
}

### Phase BE-5 — Service: VitalSignService

**Goal**: Encapsulate BMI computation and all write operations.

**Inputs**: `VitalSign` model, `Visit` model.

**Outputs**: `app/Services/VitalSignService.php`

**Steps**:
```php
<?php

namespace App\Services;

use App\Models\Visit;
use App\Models\VitalSign;

class VitalSignService
{
    public function record(Visit $visit, array $data): VitalSign
    {
        $data['bmi'] = $this->computeBmi($data['weight'] ?? null, $data['height'] ?? null);

        return $visit->vitalSign()->create($data);
    }

    public function update(VitalSign $vitalSign, array $data): VitalSign
    {
        $merged = array_merge($vitalSign->only(['weight', 'height']), $data);
        $data['bmi'] = $this->computeBmi($merged['weight'] ?? null, $merged['height'] ?? null);

        $vitalSign->update($data);

        return $vitalSign->fresh();
    }

    public function delete(VitalSign $vitalSign): void
    {
        $vitalSign->delete();
    }

    private function computeBmi(mixed $weight, mixed $height): ?float
    {
        if ($weight === null || $height === null) {
            return null;
        }

        $heightM = (float) $height / 100;

        if ($heightM <= 0) {
            return null;
        }

        return round((float) $weight / ($heightM ** 2), 2);
    }
}
```

**Decision rationale**: `update()` merges existing weight/height with incoming data before recomputing BMI — ensures BMI is correctly recalculated when only one of the two is updated. `computeBmi` guards against zero height.

**Verification**: `php artisan test --filter=VitalSignService`

### Phase BE-6 — Resource: VitalSignResource

**Goal**: Flat, AI-readable resource exposing all fields with units, flags, visit context, and previous-visit values.

**Inputs**: `VitalSign` model (with `computedFlags`), `Visit` (with `patient.user`), `VitalSignResource` pattern from `VisitResource`.

**Outputs**: `app/Http/Resources/Api/VitalSignResource.php`

**Steps**:
```php
<?php

namespace App\Http\Resources\Api;

use Illuminate\Http\Resources\Json\JsonResource;

class VitalSignResource extends JsonResource
{
    public function toArray($request): array
    {
        return [
            'id'   => (string) $this->id,
            'type' => 'vital_sign',
            'attributes' => [
                // Measurements with explicit units for AI readability
                'systolicBp'    => $this->systolic_bp,    // mmHg
                'diastolicBp'   => $this->diastolic_bp,   // mmHg
                'heartRate'     => $this->heart_rate,      // bpm
                'temperature'   => $this->temperature,     // °C
                'weight'        => $this->weight,          // kg
                'height'        => $this->height,          // cm
                'bmi'           => $this->bmi,
                'bmiCategory'   => $this->bmiCategory(),

                // Flags computed at read time
                'flags'         => $this->computed_flags,

                // Visit context (for AI trend analysis without extra queries)
                'visitId'       => (string) $this->visit_id,
                'visitDate'     => $this->whenLoaded('visit', fn () => $this->visit->date->toDateString()),
                'patientId'     => $this->whenLoaded('visit', fn () => (string) $this->visit->patient_id),
                'patientName'   => $this->whenLoaded('visit', fn () => $this->visit->patient->user->name ?? null),
                'doctorName'    => $this->whenLoaded('visit', fn () => $this->visit->doctor->name ?? null),

                // Previous-visit delta (loaded by controller when single-visit context)
                'previousVisit' => $this->when(
                    isset($this->resource->previousVitals),
                    fn () => $this->previousVitalsSnapshot()
                ),

                'createdAt'     => $this->created_at?->toIso8601String(),
                'updatedAt'     => $this->updated_at?->toIso8601String(),
            ],
        ];
    }

    private function bmiCategory(): ?string
    {
        if ($this->bmi === null) {
            return null;
        }
        $bmi = (float) $this->bmi;
        return match (true) {
            $bmi < 18.5  => 'underweight',
            $bmi >= 30.0 => 'obese',
            $bmi >= 25.0 => 'overweight',
            default      => 'normal',
        };
    }

    private function previousVitalsSnapshot(): array
    {
        $prev = $this->resource->previousVitals;
        return [
            'visitDate'   => $prev->visit->date->toDateString(),
            'weight'      => $prev->weight,
            'bmi'         => $prev->bmi,
            'systolicBp'  => $prev->systolic_bp,
            'diastolicBp' => $prev->diastolic_bp,
            'weightDelta' => $this->weight !== null && $prev->weight !== null
                ? round((float) $this->weight - (float) $prev->weight, 2)
                : null,
            'bmiDelta'    => $this->bmi !== null && $prev->bmi !== null
                ? round((float) $this->bmi - (float) $prev->bmi, 2)
                : null,
        ];
    }
}
```

**Decision rationale**: `previousVitals` is attached to the Eloquent model by the controller (not a relationship) — the controller loads it when returning a single visit's vitals (the show endpoint). The history endpoint returns a paginated collection; deltas are computable from adjacent rows. This avoids N+1 queries and keeps the resource self-contained.

### Phase BE-7 — Controller: VitalSignController

**Goal**: Thin controller — route scoping, delegation to service, ApiResponses trait.

**Inputs**: `VitalSignService`, `StoreVitalSignRequest`, `UpdateVitalSignRequest`, `VitalSignResource`, `ApiResponses` trait.

**Outputs**: `app/Http/Controllers/Api/VitalSignController.php`

**Steps**:
```php
<?php

namespace App\Http\Controllers\Api;

use App\Http\Requests\StoreVitalSignRequest;
use App\Http\Requests\UpdateVitalSignRequest;
use App\Http\Resources\Api\VitalSignResource;
use App\Models\Patient;
use App\Models\VitalSign;
use App\Models\Visit;
use App\Services\VitalSignService;
use Illuminate\Http\JsonResponse;

class VitalSignController extends ApiController
{
    public function __construct(private readonly VitalSignService $service) {}

    /** GET /patients/{patient}/visits/{visit}/vitals */
    public function show(Patient $patient, Visit $visit): JsonResponse
    {
        $this->scopeVisitToPatient($visit, $patient);

        $vitalSign = $visit->vitalSign;

        if ($vitalSign === null) {
            return $this->error('No vital signs recorded for this visit.', 404);
        }

        $this->authorize('view', $vitalSign);

        $vitalSign->load(['visit.patient.user', 'visit.doctor']);
        $vitalSign->previousVitals = $this->loadPreviousVitals($visit);

        return $this->ok(new VitalSignResource($vitalSign), 'Vital signs retrieved.');
    }

    /** POST /patients/{patient}/visits/{visit}/vitals */
    public function store(StoreVitalSignRequest $request, Patient $patient, Visit $visit): JsonResponse
    {
        $this->scopeVisitToPatient($visit, $patient);

        if ($visit->vitalSign !== null) {
            return $this->error('Vital signs already recorded for this visit. Use PATCH to update.', 409);
        }

        $vitalSign = $this->service->record($visit, $request->validated());
        $vitalSign->load(['visit.patient.user', 'visit.doctor']);

        return $this->created(new VitalSignResource($vitalSign), 'Vital signs recorded.');
    }

    /** PATCH /patients/{patient}/visits/{visit}/vitals */
    public function update(UpdateVitalSignRequest $request, Patient $patient, Visit $visit): JsonResponse
    {
        $this->scopeVisitToPatient($visit, $patient);

        $vitalSign = $visit->vitalSign;

        if ($vitalSign === null) {
            return $this->error('No vital signs recorded for this visit.', 404);
        }

        $updated = $this->service->update($vitalSign, $request->validated());
        $updated->load(['visit.patient.user', 'visit.doctor']);

        return $this->ok(new VitalSignResource($updated), 'Vital signs updated.');
    }

    /** DELETE /patients/{patient}/visits/{visit}/vitals */
    public function destroy(Patient $patient, Visit $visit): JsonResponse
    {
        $this->scopeVisitToPatient($visit, $patient);

        $vitalSign = $visit->vitalSign;

        if ($vitalSign === null) {
            return $this->error('No vital signs recorded for this visit.', 404);
        }

        $this->authorize('delete', $vitalSign);

        $this->service->delete($vitalSign);

        return $this->noContent();
    }

    /** GET /patients/{patient}/vitals */
    public function history(Patient $patient): JsonResponse
    {
        $this->authorize('viewHistory', [VitalSign::class, $patient]);

        $query = VitalSign::query()
            ->whereHas('visit', fn ($q) => $q->where('patient_id', $patient->id))
            ->with(['visit.patient.user', 'visit.doctor'])
            ->orderByDesc(
                Visit::select('date')
                    ->whereColumn('visits.id', 'vital_signs.visit_id')
            );

        if (request()->filled('from')) {
            $query->whereHas('visit', fn ($q) => $q->where('date', '>=', request('from')));
        }
        if (request()->filled('to')) {
            $query->whereHas('visit', fn ($q) => $q->where('date', '<=', request('to')));
        }

        return $this->paginated(VitalSignResource::collection($query->paginate()), 'Vitals history retrieved.');
    }

    private function scopeVisitToPatient(Visit $visit, Patient $patient): void
    {
        if ($visit->patient_id !== $patient->id) {
            abort(404);
        }
    }

    private function loadPreviousVitals(Visit $currentVisit): ?VitalSign
    {
        return VitalSign::query()
            ->whereHas('visit', function ($q) use ($currentVisit) {
                $q->where('patient_id', $currentVisit->patient_id)
                  ->where('date', '<', $currentVisit->date)
                  ->orderByDesc('date');
            })
            ->with(['visit'])
            ->first();
    }
}
```

```ts
import { NextRequest } from 'next/server'
import {
  patientsVisitsVitalsShow,
  patientsVisitsVitalsStore,
  patientsVisitsVitalsUpdate,
  patientsVisitsVitalsDestroy,
} from '@/api/generated/vital-sign/vital-sign'
import type { StoreVitalSignRequest, UpdateVitalSignRequest } from '@/api/generated/nutriBaseAPI.schemas'

type Params = { params: Promise<{ id: string; visitId: string }> }

export async function GET(_req: NextRequest, { params }: Params) {
  const { id, visitId } = await params
  const res = await patientsVisitsVitalsShow(Number(id), Number(visitId))
  return new Response(JSON.stringify(res.data), { status: res.status })
}

export async function POST(req: NextRequest, { params }: Params) {
  const { id, visitId } = await params
  const body: StoreVitalSignRequest = await req.json()
  const res = await patientsVisitsVitalsStore(Number(id), Number(visitId), body)
  return new Response(JSON.stringify(res.data), { status: res.status })
}

export async function PATCH(req: NextRequest, { params }: Params) {
  const { id, visitId } = await params
  const body: UpdateVitalSignRequest = await req.json()
  const res = await patientsVisitsVitalsUpdate(Number(id), Number(visitId), body)
  return new Response(JSON.stringify(res.data), { status: res.status })
}

export async function DELETE(_req: NextRequest, { params }: Params) {
  const { id, visitId } = await params
  const res = await patientsVisitsVitalsDestroy(Number(id), Number(visitId))
  return new Response(res.status === 204 ? null : JSON.stringify(res.data), { status: res.status })
}
```
