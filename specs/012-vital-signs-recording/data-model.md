# Data Model: Vital Signs Recording & History (012)

## Database Schema

### `vital_signs` table

| Column | Type | Nullable | Constraints | Notes |
|---|---|---|---|---|
| `id` | BIGINT UNSIGNED | No | PK, AUTO_INCREMENT | |
| `visit_id` | BIGINT UNSIGNED | No | FK → visits.id, UNIQUE, CASCADE DELETE | One vitals record per visit |
| `systolic_bp` | SMALLINT UNSIGNED | Yes | — | mmHg |
| `diastolic_bp` | SMALLINT UNSIGNED | Yes | — | mmHg |
| `heart_rate` | SMALLINT UNSIGNED | Yes | — | bpm |
| `temperature` | DECIMAL(4,1) | Yes | — | °C, e.g. 36.8 |
| `weight` | DECIMAL(5,2) | Yes | — | kg, e.g. 74.50 |
| `height` | DECIMAL(5,2) | Yes | — | cm, e.g. 175.00 |
| `bmi` | DECIMAL(4,2) | Yes | — | Computed, stored; e.g. 24.33 |
| `created_at` | TIMESTAMP | Yes | — | |
| `updated_at` | TIMESTAMP | Yes | — | |

**Constraints**:
- `UNIQUE(visit_id)` — enforces one vitals record per visit at DB level
- `ON DELETE CASCADE` on `visit_id` — deleting a visit removes its vitals record

**No `deleted_at`** — vitals are hard-deleted (no soft delete).

## Abnormal Thresholds

| Field | Flag condition | Label |
|---|---|---|
| `systolic_bp` | < 90 or > 140 mmHg | High/low systolic BP |
| `diastolic_bp` | < 60 or > 90 mmHg | High/low diastolic BP |
| `heart_rate` | < 50 or > 100 bpm | High/low heart rate |
| `temperature` | < 36.0 or > 37.5 °C | Hypothermia / fever |
| `bmi` | < 18.5 → `underweight`; 25–29.9 → `overweight`; ≥ 30 → `obese` | Weight category |

Flags are computed at read time by `getComputedFlagsAttribute()`. Not stored.

## BMI Calculation

```
bmi = weight_kg / (height_cm / 100)²
```

Computed in `VitalSignService` when both `weight` and `height` are non-null. Stored as `DECIMAL(4,2)`. Not recomputed retroactively on historical records.

| weight (kg) | height (cm) | BMI stored |
|---|---|---|
| 80 | 175 | 26.12 |
| 60 | 165 | 22.04 |
| 50 | 175 | 16.33 |
| null | 175 | null |
| 80 | null | null |

## API Resource Shape

### `VitalSignResource` — single vitals record

```json
{
  "id": "42",
  "type": "vital_sign",
  "attributes": {
    "systolicBp": 125,
    "diastolicBp": 82,
    "heartRate": 72,
    "temperature": "36.8",
    "weight": "74.50",
    "height": "175.00",
    "bmi": "24.33",
    "bmiCategory": "normal",
    "flags": [],
    "visitId": "17",
    "visitDate": "2026-05-10",
    "patientId": "3",
    "patientName": "Marko Petrović",
    "doctorName": "Dr. Amina Hadžić",
    "previousVisit": {
      "visitDate": "2026-04-01",
      "weight": "76.80",
      "bmi": "25.12",
      "systolicBp": 138,
      "diastolicBp": 88,
      "weightDelta": -2.30,
      "bmiDelta": -0.79
    },
    "createdAt": "2026-05-10T09:14:00+00:00",
    "updatedAt": "2026-05-10T09:14:00+00:00"
  }
}
```

`previousVisit` is only present on the single-visit `show` endpoint.

### Flags array — example with abnormal BP

```json
"flags": [
  { "field": "systolicBp", "value": 155, "threshold": "90–140 mmHg" },
  { "field": "bmi", "value": "31.20", "category": "obese" }
]
```
