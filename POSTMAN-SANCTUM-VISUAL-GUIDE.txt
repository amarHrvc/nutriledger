┌─ TOKEN STRUCTURE ───────────────────────────────────────────────────────────────┐
│                                                                                 │
│  Complete Token:                                                               │
│  ┌────────────────────────────────────────────────────────────────────────┐   │
│  │  2|bmBOPQ5LbGBIMkJYtgLU8OJ32hDjHB7EB4S7BejZ7c01c7b6                   │   │
│  │  │  └──────────────────────────────────────────────────────────────┘  │   │
│  │  │                     Token Hash (Base64)                         │   │   │
│  │  Token ID (Which token number)                                   │   │   │
│  │  ┌─ This is the format sent in Authorization header             │   │   │
│  │  Separator                                                       │   │   │
│  └────────────────────────────────────────────────────────────────────────┘   │
│                                                                                 │
│  Example Breakdown:                                                            │
│  ┌────────────────────────────────────────────────────────────────────────┐   │
│  │  Token ID:     2                   (Second token created)             │   │
│  │  Separator:    |                   (Pipe character)                   │   │
│  │  Hash:         bmBOPQ5LbGBIMkJY... (Unique token value)              │   │
│  │                                                                        │   │
│  │  When stored in Postman:                                             │   │
│  │  {{admin_token}} = 2|bmBOPQ5LbGBIMkJYtgLU8OJ32hDjHB7EB4S7BejZ7c01c7b6 │   │
│  └────────────────────────────────────────────────────────────────────────┘   │
│                                                                                 │
└────────────────────────────────────────────────────────────────────────────────┘

┌─ HOW POSTMAN USES THE TOKEN ────────────────────────────────────────────────────┐
│                                                                                  │
│  Step 1: Login creates token                                                   │
│  ┌──────────────────────────────────────────────────────────┐                 │
│  │ POST /api/login                                          │                 │
│  │ Body: { "email": "...", "password": "..." }             │                 │
│  │                                                          │                 │
│  │ Response:                                                │                 │
│  │ {                                                        │                 │
│  │   "data": {                                              │                 │
│  │     "token": "2|bmBOPQ5LbGBIMkJY...",                   │                 │
│  │     "user": { ... }                                      │                 │
│  │   }                                                      │                 │
│  │ }                                                        │                 │
│  └──────────────────────────────────────────────────────────┘                 │
│                      ↓                                                         │
│                      Postman captures token                                   │
│                      ↓                                                         │
│  Step 2: Store in environment variable                                        │
│  ┌──────────────────────────────────────────────────────────┐                │
│  │ pm.environment.set('admin_token',                       │                │
│  │   '2|bmBOPQ5LbGBIMkJYtgLU8OJ32hDjHB7EB4S7BejZ7c01c7b6') │                │
│  │                                                          │                │
│  │ Environment now contains:                               │                │
│  │ {{admin_token}} = 2|bmBOPQ5LbGBIMkJY...                │                │
│  └──────────────────────────────────────────────────────────┘                │
│                      ↓                                                        │
│  Step 3: Use in subsequent requests                                          │
│  ┌──────────────────────────────────────────────────────────┐               │
│  │ GET /api/patients                                       │               │
│  │                                                         │               │
│  │ Collection Auth Settings:                              │               │
│  │ ┌─────────────────────────────────────┐               │               │
│  │ │ Type: Bearer Token                  │               │               │
│  │ │ Token: {{admin_token}}              │               │               │
│  │ └─────────────────────────────────────┘               │               │
│  │         ↓ (Postman substitutes value)                │               │
│  │ Token: 2|bmBOPQ5LbGBIMkJYtgLU8OJ32hDjHB7EB4S7BejZ7   │               │
│  │         ↓ (Postman creates header)                   │               │
│  │ Authorization: Bearer 2|bmBOPQ5LbGBIMkJYtgLU8OJ32...  │               │
│  └──────────────────────────────────────────────────────────┘               │
│                      ↓                                                      │
│  Step 4: Server validates token                                            │
│  ┌──────────────────────────────────────────────────────────┐              │
│  │ Laravel receives:                                        │              │
│  │   Authorization: Bearer 2|bmBOPQ5LbGBIMkJY...          │              │
│  │                  └─ Validates against database         │              │
│  │                     (extracted hash, checked against    │              │
│  │                      user_id on token row)             │              │
│  │   ✅ Valid → Request processes with authenticated user │              │
│  │   ❌ Invalid → 401 Unauthorized                        │              │
│  └──────────────────────────────────────────────────────────┘              │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─ POSTMAN CONSOLE OUTPUT ────────────────────────────────────────────────────────┐
│                                                                                  │
│  Pre-Request Script Logs:                                                      │
│                                                                                 │
│  ✓ Using Sanctum token: 2|bmBOPQ5LbGBIMkJY...                                 │
│                         │ └─ Hash first 20 chars                              │
│                         └─ Token ID                                           │
│                                                                                │
│  Shows:                                                                        │
│  - Token ID (1, 2, 3, etc. = order created)                                  │
│  - First 20 characters of hash (uniqueness verification)                     │
│  - Format is valid (contains pipe)                                           │
│                                                                               │
│  ⚠️  No token set - run Login request first                                  │
│     → Environment variable is empty, need to login                           │
│                                                                               │
│  ❌ Invalid token format. Expected: ID|Hash                                  │
│     → Token missing pipe separator (corrupted)                               │
│                                                                               │
└────────────────────────────────────────────────────────────────────────────────┘
